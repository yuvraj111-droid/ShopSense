
# ShopSense — Online Purchase Intention Prediction

ShopSense is a beginner-friendly Machine Learning project that predicts whether an online shopping session is likely to result in a purchase.

It uses historical shopping-session data from the UCI Machine Learning Repository. After training, the saved Random Forest model can make predictions for new shopping-session details entered through the ShopSense Streamlit application.

## What ShopSense does

1. Downloads the UCI Online Shoppers Purchasing Intention dataset.
2. Separates the input features (`X`) from the target (`Revenue`).
3. Splits the historical data into training and test sets.
4. Prepares numerical and categorical features.
5. Trains a Random Forest classifier.
6. Evaluates the model on unseen test data.
7. Saves the trained model.
8. Allows users to enter new shopping-session details and receive purchase predictions.

## Setup and Run

Open a terminal inside the `ShopSense` folder.

### 1. Create a virtual environment

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
source .venv/bin/activate
```

### 2. Install libraries

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Download the dataset

```bash
python download_data.py
```

The dataset is saved to:

`data/shopsense_dataset.csv`

### 4. Train and evaluate the model

```bash
python train_model.py
```

The trained model is saved to:

`models/shopsense_model.joblib`

Evaluation results are saved to:

`reports/shopsense_results.json`

### 5. Start ShopSense

```bash
streamlit run app.py
```

The application opens in your browser. Enter shopping-session details and select **Predict Purchase Intention** to generate a prediction.

## How the Machine Learning Works

- **Features (`X`):** Shopping-session information such as administrative pages, informational pages, product pages, product browsing time, month, visitor type and weekend.
- **Target (`y`):** `Revenue`, which indicates whether the shopping session resulted in a purchase.
- **Training:** Random Forest learns patterns from labelled historical shopping examples.
- **Testing:** The model is evaluated using a separate portion of the dataset that it did not use for training.
- **Prediction:** The application uses the saved model to estimate the outcome for new shopping-session details.

The application asks users six simple questions. The selected session date is automatically converted into the month and weekend features required by the model.

The model is trained on a fixed historical dataset, but the application can accept new simulated shopping-session inputs with the same feature names and formats.

Predictions are estimates, not guarantees of customer behaviour.

## Dataset

UCI Machine Learning Repository — Online Shoppers Purchasing Intention Dataset:

https://archive.ics.uci.edu/dataset/468/online

The dataset contains 12,330 historical shopping sessions.

## Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

Actual evaluation results are saved in:

`reports/shopsense_results.json`

## Limitations

- The model is trained on a fixed historical dataset.
- Users manually enter simulated shopping-session details.
- The application is not connected to a live e-commerce website.
- Predictions depend on the quality and relevance of the input data.
